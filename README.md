# Laboratório: Teste de Mutação com a "Calculadora Mutante"

Projeto do trabalho prático de Teste de Mutação com **StrykerJS** e **Jest**.

## Resultados

| Métrica | Inicial | Final |
|---------|---------|-------|
| Cobertura de linhas | 98,64% | **100%** |
| Mutation Score | 73,71% | **100%** |

## Como executar

```bash
npm install
npm test
npm run coverage
npm run mutate
```

Relatório HTML do Stryker: `reports/mutation/mutation.html`

## Entrega

- Suíte aprimorada em `test/operacoes.test.js`
- Configuração do Stryker em `stryker.config.json`
- Relatório escrito: `Relatorio_Teste_de_Mutacao.pdf`
